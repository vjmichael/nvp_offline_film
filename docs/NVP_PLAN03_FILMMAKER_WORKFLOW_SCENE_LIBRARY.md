# PLAN-03 — An approachable filmmaker workflow backed by immutable OpenUSD and original PCM

**Design scope:** November 10, 2026. Derived from the creator's physical Windows playtest. This is a deliberate filmmaker-first interface design, not a rewrite of the durable data-first engine. Canonical PR #74 remains a draft; PLAN-03 code lives on the separate integration branch until exact-head native acceptance.

## Single creator journey

1. **Start a movie:** choose *I have an idea* or *I have a screenplay*. A connected local AI may propose a short screenplay from the idea, but is optional; the author can write or import without a model. Show only title, idea/script, and one primary action.
2. **Write and review:** one editable screenplay, its revision history, and one explicit **Ask local AI for a screenplay draft** action. AI text is a proposal, not automatically the approved screenplay. Saving/replacing the screenplay remains an affirmative human action.
3. **Scene Library:** a list of scenes extracted from the *current saved screenplay*; clicking one opens the scene workspace, which displays scene heading/location, character cues/actors, props (only approved scene-linked story-bible entities; otherwise mark as unassigned), dialogue and script excerpt. Never treat speculative NLP guesses as approved production facts.
4. **Work on one scene:** present only its immediate next actions: screenplay context, reviewed assets/roles, stage/block, direct/film, and source/sound. The existing specialist tools remain accessible, but are *not* 18 default top-level navigation buttons.
5. **Review the movie:** chronological scene progression, derived approved previews, continuity checks and sound. Source Digital Takes and original PCM remain immutable; no auto-generation of final pictures or DCPs without review.
6. **Advanced Studio:** technical details, exact Film Time, actor calibration, rigging, skinning, color, camera rail, resource/custody traces, source hashing, render workers and export compliance. Advanced controls are accessible but hidden by default and do not block story work.

## Navigation contract

- Default top level: **Story**, **Scene Library**, **Film review** (pending real implementation); **Advanced Studio** is a disclosure, not a new collection of always-visible steps.
- New/open project starts at Story (if no saved scenes) or Scene Library (if saved screenplay has scenes).
- Selecting a scene preserves the existing scene identity generated by `parse_screenplay` (heading + occurrence); changes to screenplay or revision reload the library and retain source provenance.
- Scene workspace never invents locations, props, ActorIDs, rigged assets or approved actor cast from plain words. Explicitly distinguish **screenplay-mentioned character**, **scene-linked approved Story Bible asset**, and **not yet assigned**.
- Navigation does not independently authorize recording, model inference, immutable Take publication, native render or export.
- Film review entry may be unavailable if no final assembly yet; do not pretend finished movie output exists.

## First-slice implementation

- A **read-only source-grounded scene breakdown endpoint** based on the current SQLite screenplay and existing Story Bible; no model needed. It returns exact scene ID/revision/heading, parsed character cues and dialogue, approved scene-linked entities (if any) and an explicit *unassigned* props value.
- A Scene Library component with scene list and selected scene detail, including direct focused entry points to existing specialist stage/direct/sound tools. Source editor remains usable.
- A single locally connected AI screenplay draft action using existing `IdeaPipeline` and `writer_for`; it stays a reviewed proposal before `use_as_screenplay`.
- Compact UI: progressive disclosure and no requirement to choose among 18 production tabs at start. Keep existing advanced pages without removing functionality.
- Native tests prove no fabricated props, no cross-project leakage, revision freshness, and protected source immutability; React tests show scenes are selectable, AI output is not silently approved, and Advanced Studio is not open by default.
