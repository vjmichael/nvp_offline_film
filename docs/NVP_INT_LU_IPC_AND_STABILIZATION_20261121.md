## Required development phase order

1. **Integration**: Finish all existing NVP components and add **NVP-INT-LU-01** to interface with Lu Core's developing IPC.
2. **Stabilization**: Finish **NVP-STAB-01** — a complete codebase sweep, integration repairs, bug fixes, simplification, UX polish, documentation and coverage reconciliation.
3. **Security qualification**: Only after stabilization's reviewed source gate, conduct **NVP-SEC-Q-01** (including already implemented POST-01F native signing/encrypted review). Existing source/negative security receipts remain useful, not final security clearance.
4. **Preparation for installed acceptance + real installed qualification**: **NVP-INST-AC-01**, actual supported Windows service/key/approval/UI and native runtime evidence; packaging fixtures may exist earlier without constituting release.
5. **Windows alpha installer closeout**: **NVP-PKG-WIN-01**, one actual NVP installer, verified install/update/uninstall/rollback and release acceptance. No separate LTX installer.

NVP retains an **independently installable, offline-first Windows alpha** with its own filmmaking UI, scene/Take/editor/audio/export domain and original media. A separate **optional Lu-connected mode** exposes its `nvp.film.*` Workspace/provider capabilities to a properly installed/enrolled Lu Core. NVP must remain useful when Lu is absent or offline; connected NVP must NOT launch a duplicate Lu GGUF/model server, rewrite creator-approved data or acquire privileges from an IPC claim. This supersedes prior "NVP is only a future Lu DLC/no standalone NVP app" assumptions for the Windows alpha. Model-independent filmmaking works standalone; independent NVP inference fallback, if offered, needs its own explicit policy and must not compete with an attached Lu model.

## NVP-STAB-01 — Mandatory whole-codebase stabilization before security

**Not a limited POST security re-test.** Review all NVP Python, React/WebView2, services, native workers, SCM/CNG/EFS custody, renderer/Blender/OpenUSD, scene/timeline/FilmIndex, low-poly-to-LTX interface, Basic/Advanced node-graph templates, PCM and native cinema DCP, storage/encryption/revisions, CI/build packaging, dependencies, docs and UX. Cover standalone and Lu-connected modes.

| **STAB-01D — simplify/consolidate** | Trace and remove truly redundant services, model managers, duplicate wrappers/conversions, obsolete helpers and deps only with usage/provenance review, safe migration and regression; one coherent NVP implementation, no dropped capabilities, security shortcuts or feature freeze against minor polish |
