## Filmmaker workflow

The creator opens **Export Film → Final Picture and Sound**, chooses the finishing look and overall sound level, optionally auditions a real source-based frame or a 3-second extract from the genuinely measured full-program source mix, saves director notes and approves the exact current film. Any newer edit or approved scene, actor or acoustic change makes the existing finishing approval stale; a new source-bound revision must be reviewed. Prior versions are retained and restoring a version creates another history entry without overwriting the source.

The creator can then **Finish and Save Movie** through the existing independently contained G08 host path (ordinary film) or the existing G03 sealed in-memory delivery path (protected movie). The result is currently a **640×360 24fps 8-bit display-referred sRGB SDR MJPEG + 48kHz stereo PCM16 AVI working film** with source-bound final color and audio settings. This is NOT ProRes, cinema-resolution master, scene-linear EXR, ACES-certified OCIO, verified HDR or a DCP. Show these distinctions openly without exposing technical controls in the filmmaker interface.

Completed movie cards include measured actual final PCM loudness and sample peak; where selected, they report whether the reviewed loudness goal was met. They also allow saving **Picture & Sound Files**, a SHA-verified picture JPEG sequence + real stereo 48k PCM16 WAV + manifest ZIP derived from the already independently decoded AVI. The package preserves source output fidelity, which is limited by the working MJPEG/PCM16 renderer. A ZIP cannot increase scene pixel precision or qualify as theatrical output.
