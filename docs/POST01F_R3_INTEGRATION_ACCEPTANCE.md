## R1-vs-R2 compatibility decision

R1's direct `ltx_pipelines.ic_lora` CLI must be **wrapped** by an installed reviewed host-owned broker; do not launch a free-form Python `-m` command from the UI/model. The broker consumes `--nvp-ltx-job` and resolves only verified local model assets/derived files, executes the approved native pipeline, emits a **picture-only** bounded result and exact host-bound receipt. Host then authenticates original Take, result bytes, independent picture decode and OS/GPU evidence and holds result quarantined for explicit filmmaker review. The R1/R2 contract difference is intentionally visible, not glossed over.
