## Task group A — Model to source draft, with host recovery

Existing NVP native WO6 `verified_writer_for` / `ProvenLocalModelWriter` is the only selected loopback model adapter. The browser supplies a model ID selected from WO6 discovery and plain film direction, never an HTTP endpoint, script, plugin, worker executable, OS grant or creative approval. `backend/nvp_usd_film02m_g_model_world_candidate.py` uses a bounded read-only source catalog and expects exactly one JSON `params` object with eight generator fields, approved prototype IDs/revisions, finite metre origins, and the stricter existing 02M-E1 maximum source budgets. Model-provided JSON and provider self-reported completion tokens do not prove an underlying GGUF SHA; independent native `OriginalFilmDistrict.plan/_stage` checks true 3D source/PointInstancer geometry and layers.

`OriginalDistrictDrafts` adds WAL/FULL `authoring_model_attempts` and `authoring_model_evidence`. Attempts begin `GENERATING` before the model completion; invalid provider replies end `FAILED`; changed process session during a pending model call becomes `INTERRUPTED_REQUIRES_NEW_GENERATION`. No orphan attempt is executable or automatically resumed. A valid model candidate and provenance transition to `DRAFT_SAVED` in the **same SQLite transaction** as the unapproved draft. Reopen reads source-verified original USD and provenance; edits/undo/discard retain their original native authority rules. Approval is still a separate, native, source-exact first-party OS dialog; an AI proposal is never a grant.

The React 23 editor discovers real installed local models through WO6, records the source version and model SHA receipt, provides durable attempt status and native read/undo/discard. A manually selected `proposed_by=ai` label is NOT treated as model execution evidence.

The native host exposes source preview and a **separate** exact-preview-SHA OS approval to publish one immutable FilmIndex `presentation` binding with dependencies on approved district, original frozen world Take, shot camera and source Takes. The 01F Blender/Cycles shot renderer and 01T finished 720-frame 48-kHz movie are distinct still-open end-to-end gates.
